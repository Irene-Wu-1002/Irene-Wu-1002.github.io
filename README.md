# Personal Website

This is my personal website built with HTML, CSS, and JavaScript, hosted on GitHub Pages.

## Features

- Responsive design that works on all devices
- Modern, clean interface
- Smooth scrolling navigation
- Interactive animations
- Contact information and social links
- Project showcase section

## Customization

To customize this website for your own use:

1. **Update personal information:**
   - Replace "Your Name" with your actual name
   - Update the hero subtitle with your profession/title
   - Modify the about section with your own story
   - Add your actual skills to the skills section

2. **Add your projects:**
   - Replace the placeholder projects with your actual work
   - Add real project images
   - Update project links to point to live demos and GitHub repositories

3. **Update contact information:**
   - Replace email addresses with your own
   - Update social media links (GitHub, LinkedIn, Twitter)
   - Add or remove contact methods as needed

4. **Customize styling:**
   - Modify colors in `styles.css`
   - Change fonts by updating the Google Fonts link
   - Adjust spacing, sizes, and layout as desired

## Deployment

This website is designed to be deployed on GitHub Pages:

1. Create a new repository named `yourusername.github.io`
2. Upload these files to the repository
3. Enable GitHub Pages in the repository settings
4. Your website will be available at `https://yourusername.github.io`
